QUESTIONS FRÉQUENTES

Vous vous demandez…

Combien coûte une application web sur mesure ?

Une première version utilisable se situe généralement entre 15 000 et 40 000 CHF selon le périmètre : nombre d’écrans, complexité des règles métier, intégrations avec vos outils existants. Nous découpons toujours le projet pour que vous obteniez quelque chose d’utile rapidement, plutôt qu’un grand projet qui n’arrive jamais.

Combien de temps pour développer une application web ?

Comptez 4 à 8 semaines pour une première version que vos équipes utilisent vraiment. Vous voyez une maquette dès la deuxième semaine et une démo chaque vendredi : le projet avance sous vos yeux, et vous pouvez réorienter en cours de route sans tout casser.

Quelles technologies utilisez-vous ?

Des technologies web éprouvées et largement répandues, choisies pour leur stabilité et la facilité à trouver des développeurs — jamais pour faire moderne. Concrètement, cela signifie que votre application peut être reprise par une autre équipe si vous le souhaitez un jour : vous n’êtes prisonnier de personne.

À qui appartient le code ?

À vous, intégralement. Le code source, la base de données et les comptes d’hébergement sont à votre nom dès le premier jour. Nous ne pratiquons pas la rétention de code : si vous décidez de partir, vous partez avec tout.

L’application pourra-t-elle évoluer plus tard ?

C’est prévu dès la conception. Nous construisons des bases propres et documentées pour que les fonctionnalités suivantes s’ajoutent sans tout reprendre. La plupart de nos clients font évoluer leur outil chaque trimestre : c’est le principe même d’un partenariat de long terme.
